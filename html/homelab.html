Home Lab

PURPOSE

My home lab is where I learn and where I test new systems, services and automations before I rely on them. The network sits behind an OPNsense firewall with no inbound ports open, and a MikroTik switch splits it into three VLANs. Core services run on an always-on Ubuntu server. Heavier workloads run as virtual machines on a Dell DL4300 Proxmox host that I power on only when I need it.

NETWORK TOPOLOGY

ALWAYS-ON SERVER

A custom-built Intel i5 PC running Ubuntu Server hosts the services that need to be available around the clock.

  • UniFi Controller
  • Grafana
  • Prometheus
  • HashiCorp Vault

PROXMOX VIRTUAL MACHINES

The Dell DL4300 was originally built as the training environment for UNF's National CCDC team. It now runs the Proxmox hypervisor and powers on only when needed. Each VM and its allocated resources:
