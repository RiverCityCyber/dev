PROJECT O.D.A.S.H.I.

Project O.D.A.S.H.I. (Onboard Diagnostics Assistant Serving Helpful Information) is a Raspberry Pi 5 based CAN-Bus/K-line reader and dash-cam system. It is designed to be a custom solution for handling a variety of smart-car features in a secure manner. The system utilizes a Raspberry Pi 5, USB camera, buck converter, audio DAC, and CAN-Bus interface to provide the following features:

  1. Car system diagnostics
    • Engine and system performance
    • Any error codes (such as check engine lights)
    • Oil, coolant, and battery levels
    • Other system data as needed
  2. Dashcam recording
  3. Apple Carplay
  4. Voice activated commands
  5. Maintenance reminders based on odometer reading

BUILD YOUR OWN PI DASH-CAM

  1. Install Raspberry Pi OS Lite (or distro of choice) on a Raspberry Pi
  2. Connect USB camera of choice (I am using a Logitech Webcam)
  3. Update the system (sudo apt update && upgrade)
  4. Run the following to show your webcam's information 
    v4l2-ctl --list-devices
  5. Create the following script in /usr/local/bin/ 
    #!/bin/bash
cd /home/pi/videos
find /home/pi/videos -type f -name "*.mjpeg" -mtime +14 -delete

ffmpeg -f v4l2 -input_format mjpeg -video_size 1280x720 -framerate 30 \
  -i /dev/video0 -c:v copy -f segment -segment_time 60 \
  -segment_atclocktime 1 -strftime 1 "dashcam_%Y%m%d_%H%M%S.mjpeg"
  6. Set the script to run on startup
    7. Now you have a fully functioning dashcam that should record all video while running and store locally. To expand it to the full ODASHI setup, follow the next step.

BUILD YOUR OWN ODASHI

  • Install react-carplay
  • Attach a CarPlay converter from CarlinKit
  • Connect the Raspberry Pi to a touchscreen (I prefer the Adafruit 3.5" TFT LCD)
  • Start customizing to your need!

    Versioning will happen in two methods of tracking: software and hardware. This will be denoted by vX.Y.Z, where X = new hardware release, Y = new software release, and Z = software or hardware patches.


    Hardware Versioning

    v1.#.#

    Power, Display, Audio, Enclosure - Simple powering of the Raspberry Pi 5, with touchscreen display, audio, and an enclosure to promote proper airflow. The basics, but the biggest demand of any version.


    v2.#.#

    Adding Sensors - Add a K-line reader, and TMPS sensor to display out.


    v3.#.#

    Hinged Display - Allow the display to open and close based on a hinge and push-push latch feature. Precursor to motorized opening. Advantage to this is being able to easily open the enclosure to access the Pi without having to remove trim pieces.


    v4.#.#

    Motorized Display Opening - Add a motor to the hinged opening, allowing for easier access to the Raspberry Pi. Plus, it being motorized is just cool.


    v5.#.#

    IR Remote Integration - I have an old Apple IR remote. Integrate this with an IR sensor to allow control of the dispaly and system through the remote.


    v6.#.#

    Local AI Integration - Add hardware AI module to locally run small AI models. Focused on voice commands, automation, and sensor readings/diagnostics.


    Software Versioning

    v#.1.#

    Carplay, Audio, and basic on/off - Version 1 is geared towards the most basic usage: carplay, bluetooth audio, and graceful shutdown. PWM for the display, and other stuff I cannot think of right now.


    v#.2.#

    Custom Dashboard - Maintenance reminders and a settings page.


    v#.3.#

    K-line readings - Diagnostics page, with live sensor readings.


    v#.4.#

    Bluetooth Audio Display - Display bluetooth audio without relying on Apple Carplay. Show equalizer, car graphics, etc.


    v#.5.#

    IR Remote Integration - Software to support IR remote integration.


    v#.6.#

    Local AI Integration - Push to talk voice communication with the local AI, giving it diagnostics ability, readout capability of diagnostics, and generic chat features. No internet access, local ONLY.
