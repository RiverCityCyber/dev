This Website

OVERVIEW

rivercitycyber.com is a static site I write by hand in HTML, CSS and JavaScript, with no framework or site generator. I use it to practice front-end development and web security, and to document my projects. The full source is on GitHub.

HOSTING & SECURITY

  • Cloudflare Pages deploys straight from the GitHub repository on every push, with HTTPS enforced.
  • Strict Content Security Policy. Scripts may only load from this site and two pinned origins, and inline scripts and event handlers are blocked. That means no onclick attributes anywhere on the site.
  • Other security headers: HSTS, X-Content-Type-Options, a strict referrer policy, frame-ancestors 'none' against clickjacking, and a Permissions-Policy that turns off the camera, microphone and geolocation.
  • Cloudflare bot protection in front of the site.

DESIGN & STRUCTURE

  • Design tokens. Every color, font size and spacing step is a CSS custom property, so the light and dark themes are only a handful of overrides. With no saved choice, the theme follows your operating system.
  • Shared layout without a framework. The header and footer live once in partials/. A small Python script (tools/sync_layout.py) stamps them into every page and marks the current page in the nav. A --check mode catches pages that have drifted out of date.
  • Accessibility: keyboard-reachable menus, reduced-motion support and fluid type that respects your browser's font size.
