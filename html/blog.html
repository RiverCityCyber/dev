SETTING UP VS CODE

May 9, 2026

VS Code has a huge extension ecosystem. One setting I rely on is format-on-save with Prettier, which keeps HTML consistent without any extra effort.

  1. Install the Prettier extension (esbenp.prettier-vscode).
  2. Open the Command Palette (Cmd + Shift + P on macOS) and run Preferences: Open User Settings (JSON).
  3. Add the following and save: 
    "[html]": {
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true
}

Every HTML file is now formatted automatically when you save it.
