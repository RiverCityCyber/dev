HOME LAB INFRASTRUCTURE

A segmented network behind an OPNsense firewall with no open ports, split into three VLANs on a MikroTik switch.

An always-on Ubuntu SFF server runs monitoring, secrets and Wi-Fi management. A custom Proxmox host runs VMs on demand, a Dell DL4300 handles storage and backups, and Tailscale provides remote access.

STACK: OPNsense • MikroTik • VLANs • Proxmox • Prometheus • Grafana • Vault • Tailscale
